cmangos classic-db: derived data in this addon
===============================================

Files that carry data derived from it:

  Data/Spots.lua      object and creature spawn positions (turned into map percents, routes and farming areas), which
                      object carries which lock, creature names and levels, pool sizes, fishing base skill per zone
  Data/Trainers.lua   NPC positions (turned into map percents) and the limited stock of recipe vendors

Source:

  cmangos classic-db, the world database of the Continued MaNGOS project for World of Warcraft 1.12
  https://github.com/cmangos/classic-db
  Full dump used: Full_DB/ClassicDB_1_12_1_z2815.sql.gz
  https://raw.githubusercontent.com/cmangos/classic-db/master/Full_DB/ClassicDB_1_12_1_z2815.sql.gz

The two files are generated by tools/gen_spots.py and tools/gen_npcs.py, which are part of this repository and are
the complete "source" of the transformation: run them against the dump above to rebuild the files
(docs/spots-data.md has the commands). The dump itself is not redistributed here.

The data is Classic 1.12 data. WoW: Forever may place things elsewhere: the files mark it (classic = true) and the
addon labels it as unconfirmed.
